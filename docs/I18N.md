# Internacionalização (i18n)

O Nexum Tower suporta três idiomas:

| Código | Idioma | URL |
|--------|--------|-----|
| `pt` | Português (padrão) | `/` |
| `en` | English | `/en` |
| `es` | Español | `/es` |

## Onde ficam as traduções

```txt
apps/web/messages/
├── pt.json
├── en.json
└── es.json
```

## Configuração compartilhada

Locales e tipos ficam em `packages/shared/src/i18n/locales.ts` para reutilização no backend e em outros apps do monorepo.

```typescript
import { locales, defaultLocale, type Locale } from "@nexum-tower/shared";
```

## Frontend (Next.js)

- Biblioteca: [next-intl](https://next-intl.dev)
- Rotas: segmento dinâmico `app/[locale]/`
- Middleware: detecção e redirecionamento de locale
- Seletor de idioma: componente `LocaleSwitcher` no header

## Adicionar novas strings

1. Adicione a chave nos três arquivos JSON (`pt`, `en`, `es`)
2. Use no componente:

```tsx
// Server Component
import { getTranslations } from "next-intl/server";
const t = await getTranslations("namespace");

// Client Component
import { useTranslations } from "next-intl";
const t = useTranslations("namespace");
```
